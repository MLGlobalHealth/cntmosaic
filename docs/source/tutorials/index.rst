Tutorials
=========

The tutorials are Jupyter notebooks. Each one can be opened in Google Colab from the
badge at its top, or downloaded from the
`repository <https://github.com/MLGlobalHealth/cntmosaic/tree/main/docs/source/tutorials>`_
and run locally.

Tutorial 04 takes long to run, so it is shown here without its outputs.
Run it locally or in Colab to see the results.
